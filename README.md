# GLO Aesthetics + Wellness Lounge — Website

Static export of the site (originally built as a Claude Design canvas artifact) for Ocala, FL medspa client GLO Aesthetics + Wellness Lounge.

## Structure
Plain static HTML/CSS/JS. Each file sits at its canonical URL: `index.html` is `/`, `treatments/xeomin.html` is
`/treatments/xeomin`, `treatments/index.html` is `/treatments`, `locations/ocala.html` is `/locations/ocala`.
See `CLAUDE.md` for the SEO/AEO page standard every page must meet and the scripts that check it.

- `sitemap.xml`, `llms.txt`: generated by `scripts/build_seo_files.py`
- `robots.txt`: allows search and AI crawlers
- `404.html`: branded not-found page
- `content/treatments/`: treatment page content data

## Hosting
Hosted on **Vercel**. The site is static, so no build step is needed. The `glo-website` Vercel project is linked to this repo:

- A push to `main` deploys to production.
- Every branch and PR gets its own preview URL.
- `vercel.json` turns on clean URLs, 301s the old `/Treatment-*` and `/Category-*` addresses to the new ones, and sends
  `X-Robots-Tag: noindex` on `*.vercel.app` hosts so previews stay out of search.

`firebase.json` and `.firebaserc` are left in place in case Firebase Hosting is used later (`firebase deploy --only hosting`).

## Assets
Images from the original Claude Design project live in `assets/` (logo, home hero, Cherry financing images). Other photos load from the Higgsfield CDN.

## Local preview
Clean URLs need a server that maps `/treatments/xeomin` to `treatments/xeomin.html`, e.g. `npx vercel dev` or
`npx serve` (which supports clean URLs by default).
